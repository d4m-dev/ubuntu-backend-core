Hệ Thống Ubuntu Backend Core

Hệ sinh thái máy chủ cục bộ tối ưu hóa cho di động. FastAPI, Google Gemini AI, Demucs Audio Studio, và hạ tầng tự động hóa lịch trình (Google Calendar Integration). Vận hành biệt lập tại cổng 16868.

Sơ Đồ Cấu Trúc Hệ Thống

ubuntu-backend-core/

├── main.py # Entry point: Uvicorn Server

├── .env # Biến môi trường (Hidden)

├── auth/ # Chìa khóa Google Cloud (d4m-calendar-key.json)

├── core/

│ ├── database.py # MariaDB Driver & Connection Pool

│ ├── gcal.py # Logic đồng bộ Lịch Google thông minh

│ ├── tg_handlers.py # J.A.R.V.I.S Telegram Bot Engine

│ └── security.py # Xác thực JWT SSO

├── api/

│ ├── ai_admin.py # Bộ não AI xử lý lệnh lịch & hệ thống

│ ├── audio_engine.py# Xử lý Demucs & Whisper AI

│ └── dashboard.py # API giám sát tài nguyên (CPU/RAM)

├── scripts/

│ ├── deploy.py # Máy phóng code lên GitHub (Auto Sync)

│ └── network_tunnel.py# Quản lý Cloudflare Tunnel

└── public/ # Giao diện Native Calendar & Dashboards
